# AI & Machine Learning Track

Welcome to the official repository for the **AI & Machine Learning Track**.

This repository contains the learning resources, practical exercises, examples, datasets, project guidelines, and supporting materials used throughout the track.

The program is designed around **learning by building**. Students will move from understanding core AI and machine learning concepts to developing practical applications using machine learning models and Large Language Model (LLM) APIs.

---

## 🎯 Track Objectives

By the end of the track, students should be able to:

- Understand the foundations of Artificial Intelligence and Machine Learning
- Prepare and analyze datasets for machine learning
- Build classification and regression models
- Evaluate and improve machine learning models
- Understand modern Generative AI and Large Language Models
- Work with LLM APIs
- Design effective prompts for AI applications
- Build simple AI-powered applications
- Use Git and GitHub for project development
- Build and present a real-world AI capstone project

---

## 🧠 What We Will Learn

The track focuses on two main areas.

### 1. Machine Learning

Students will learn the complete machine learning workflow:

- Understanding the problem
- Data collection and exploration
- Data cleaning
- Feature preparation
- Training models
- Classification
- Regression
- Model evaluation
- Comparing models
- Making predictions
- Building a simple interface around a trained model

The goal is not only to train models, but to understand how machine learning can be applied to real-world problems.

---

### 2. Generative AI & LLM Applications

Students will learn how modern Large Language Models can be integrated into applications.

Topics include:

- Understanding Generative AI
- Understanding Large Language Models
- Prompt engineering
- System and user prompts
- Structured outputs
- LLM API integration
- Managing API responses
- Error handling
- Building AI-powered workflows
- Creating simple AI applications

The focus will remain practical and application-oriented.

## 📚 Learning Approach

This track follows a practical learning approach:

**Learn → Practice → Build → Evaluate → Improve**

Each major concept will be supported by practical demonstrations and exercises.

Students are expected to write code, experiment with models, make mistakes, evaluate results, and improve their solutions.

---

## 🧪 Practical Work

Throughout the track, students will complete guided practical exercises covering areas such as:

### Machine Learning

- Dataset exploration
- Data preprocessing
- Classification
- Regression
- Model evaluation
- Prediction

One of the guided projects includes a **Student Performance Prediction System**, where students practice the complete machine learning workflow before beginning their independent capstone projects.

### Generative AI

Students will also build small applications using LLM APIs to practice:

- Prompt design
- API integration
- Structured AI responses
- User input handling
- AI application development

---

## 🚀 Capstone Project

At the end of the track, students will build a **real-world AI application**.

The capstone is not intended to be a generic tutorial project.

Each project must:

- Solve a clearly defined real-world problem
- Identify a specific target user
- Use either Machine Learning or an LLM API
- Have a realistic and manageable scope
- Demonstrate what the student learned
- Include a working application or interface
- Be documented properly
- Be completed within the provided project period

Examples of project areas may include:

- Agriculture
- Education
- Employment
- Business
- Logistics
- Humanitarian work
- Public services
- Retail and operations

Detailed project options and requirements will be provided in the `capstone/` directory.

## 🤖 Capstone Tracks

Students will work within one of two technical directions.

### Machine Learning Project

A machine learning project may follow:

Problem  
↓  
Dataset  
↓  
Data Analysis  
↓  
Data Preprocessing  
↓  
Feature Preparation  
↓  
Model Training  
↓  
Model Evaluation  
↓  
Prediction  
↓  
Application Interface

Examples include classification and regression problems based on real-world datasets.

### LLM Application

An LLM-based project may follow:

Problem  
↓  
User Input  
↓  
Prompt Design  
↓  
LLM API  
↓  
Structured Response  
↓  
Application Logic  
↓  
User Interface  
↓  
Testing & Improvement

LLM capstones should solve a specific workflow or human problem rather than simply generating random text.
